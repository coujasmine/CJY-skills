# UTD24 Strategy / Innovation / Entrepreneurship — Parent Theory Lineages

This file is the **parent-theory quick reference** for Dim 2 (Literature Conversation). Use it to:

1. **Test if the user's claimed parent theory matches the actual lineage they're describing.** Many drafts misname their parent theory.
2. **Suggest 3 candidate parent theories in IDEA mode** when the user's idea fits multiple lineages.
3. **Calibrate which UTD24 outlet best fits a given lineage** (some lineages are SMJ-natural, others ASQ-natural, others AMR-natural).

For each lineage: **central question**, **2-4 canonical citations**, **2-3 recent UTD24 papers in the lineage**, **typical method tier**, **outlet fit**, **mis-application warnings**.

## A. Strategy / Resource & Capabilities lineages

### A1. Resource-Based View (Penrose-Wernerfelt-Barney)

- **Central question**: Why do firms differ in performance? Which resources confer sustainable advantage?
- **Canonical**: Penrose 1959 *The Theory of the Growth of the Firm*; Wernerfelt 1984 SMJ; Barney 1991 *J Management*; Peteraf 1993 SMJ.
- **Recent UTD24 in lineage**: [CITATION NEEDED — user supplies; see "Recent-anchor search guide" below for query template]
- **Typical method**: archival panel with firm-level RBV-style measures; sometimes IV for resource endowment.
- **Outlet fit**: SMJ (natural home), AMJ (when behavioral/HR mechanism), AMR (pure-theory extensions).
- **Mis-application warnings**:
  - Calling any firm-level variable "a resource" without VRIN scrutiny → reviewer reject.
  - Citing Barney 1991 without engaging the critiques (Priem & Butler 2001 etc.) → looks dated.
  - "Resources" as black-box construct without specifying type (physical / human / organizational / knowledge) → mechanism unclear.

### A2. Dynamic Capabilities (Teece-Pisano-Shuen, Helfat-Peteraf-Eisenhardt)

- **Central question**: How do firms adapt resource portfolios to changing environments?
- **Canonical**: Teece, Pisano & Shuen 1997 SMJ; Eisenhardt & Martin 2000 SMJ; Helfat et al. 2007 *Dynamic Capabilities*; Helfat & Peteraf 2015 SMJ.
- **Recent UTD24 in lineage**: [CITATION NEEDED — user supplies; see "Recent-anchor search guide" below for query template]
- **Typical method**: panel data with reconfiguration events (acquisitions, divestitures, alliances); occasionally formal modeling.
- **Outlet fit**: SMJ (primary), OS (when cognitive/managerial capability angle).
- **Mis-application warnings**:
  - "Dynamic capabilities" used as synonym for "any organizational change" → reviewer reject.
  - No distinction between routine adaptation and dynamic capability → vagueness flag.
  - Recent Helfat & Peteraf 2015 "managerial cognitive capability" is the active growth edge — older Teece 1997 framing alone reads dated.

### A3. Transaction Cost Economics / Governance (Williamson)

- **Central question**: When does a firm choose to make vs buy vs ally? How do governance structures align with transaction attributes?
- **Canonical**: Coase 1937; Williamson 1975, 1985, 1991; Hennart 1993.
- **Recent UTD24 in lineage**: [CITATION NEEDED — user supplies; see "Recent-anchor search guide" below for query template] (recent extensions often integrate property rights or capabilities — see Argyres & Zenger 2012 SMJ).
- **Typical method**: archival panel of governance choices (M&A, alliances, contracts); occasional experiment.
- **Outlet fit**: SMJ (primary), Strategy Science, OS.
- **Mis-application warnings**:
  - "Asset specificity" / "uncertainty" measured without theoretical defense of operationalization.
  - Ignoring the capabilities critique (Madhok 2002, etc.) → looks like 1990s paper.

### A4. Adner-Kapoor Ecosystems / Architectural

- **Central question**: When focal-firm performance depends on complementary innovations from external partners, how do ecosystem architecture and complementor dependencies shape outcomes?
- **Canonical**: Adner & Kapoor 2010 SMJ; Adner 2017 *J Management*; Jacobides, Cennamo & Gawer 2018 SMJ.
- **Recent UTD24 in lineage**: [CITATION NEEDED — user supplies; see "Recent-anchor search guide" below for query template]
- **Typical method**: archival panel of ecosystem participants; sometimes formal modeling (Clough 2026 SS pattern).
- **Outlet fit**: SMJ (primary), Strategy Science (when formal/typological), OS.
- **Mis-application warnings**:
  - Calling any value chain an "ecosystem" → conceptual drift.
  - No specification of focal firm vs complementor positioning → mechanism unclear.

## B. Behavioral Strategy lineages

### B1. Carnegie School / Behavioral Theory of the Firm (BTF)

- **Central question**: How do organizational search, aspiration adaptation, and slack shape firm decisions and innovation?
- **Canonical**: Cyert & March 1963; Greve 2003 AMJ; Argote & Greve 2007 OS.
- **Recent UTD24 in lineage**: [CITATION NEEDED — user supplies; see "Recent-anchor search guide" below for query template]
- **Typical method**: archival panel with aspiration / performance-feedback measures; sometimes lab experiment.
- **Outlet fit**: ASQ (natural home for BTF), AMJ, OS, SMJ.
- **Mis-application warnings**:
  - Using "performance feedback" as label without modeling aspiration formation → looks superficial.
  - Conflating BTF with prospect theory → distinct lineages.

### B2. Attention-Based View (Ocasio)

- **Central question**: How does the focus and channeling of organizational attention shape strategic action?
- **Canonical**: Ocasio 1997 SMJ; Ocasio 2011 OS; Joseph & Wilson 2018 SMJ.
- **Recent UTD24 in lineage**: [CITATION NEEDED — user supplies; see "Recent-anchor search guide" below for query template]
- **Typical method**: text analysis of communications (10-K, transcripts) for attention measurement; archival panel.
- **Outlet fit**: SMJ, AMJ, OS.
- **Mis-application warnings**:
  - "Attention" measured as frequency of word mentions without theoretical justification.
  - No distinction between top-down attention focus and bottom-up attention channeling.

### B3. Top Management Team (TMT) / Upper Echelons (Hambrick-Mason)

- **Central question**: How do TMT characteristics shape strategic choices and firm outcomes?
- **Canonical**: Hambrick & Mason 1984 AMR; Hambrick 2007 AMR.
- **Recent UTD24 in lineage**: [CITATION NEEDED — user supplies; see "Recent-anchor search guide" below for query template]
- **Typical method**: archival panel of TMT demographic measures linked to strategic outcomes.
- **Outlet fit**: SMJ (primary), AMJ.
- **Mis-application warnings**:
  - "TMT characteristics → outcomes" without specifying mechanism = critique target (Hambrick 2007 explicitly warns).
  - Using demographic proxies for cognitive constructs without theoretical bridge.
  - User's "ai-tmt-myopia 0517v1" project (from memory) sits here — JBR primary fit per venue-fit memo; SMJ would require strong mechanism + identification.

### B4. Csaszar-Gavetti / Cognitive Strategy

- **Central question**: How do managerial mental representations / cognitive maps shape strategic choice and firm performance?
- **Canonical**: Gavetti 2005 OS; Csaszar 2018 SMJ; Csaszar, Ketkar & Kim 2024 Strategy Science.
- **Recent UTD24 in lineage**: [CITATION NEEDED — user supplies; see "Recent-anchor search guide" below for query template]
- **Typical method**: lab experiments with managers / entrepreneurs / MBA students; sometimes formal modeling.
- **Outlet fit**: Strategy Science (primary), OS, SMJ.
- **Mis-application warnings**:
  - "Cognition" used vaguely without identifying which mental construct (representation / belief / heuristic / mental model).
  - Lab experiment with student samples without ecological-validity defense.

## C. Innovation lineages

### C1. Henderson-Clark Architectural / Modular

- **Central question**: How do changes in component vs architectural knowledge differentially affect incumbent advantage?
- **Canonical**: Henderson & Clark 1990 ASQ; Baldwin & Clark 2000 *Design Rules*.
- **Recent UTD24 in lineage**: [CITATION NEEDED — user supplies; see "Recent-anchor search guide" below for query template]
- **Typical method**: archival panel of patent / product / technology data.
- **Outlet fit**: ASQ, SMJ, OS.
- **Mis-application warnings**:
  - "Architectural innovation" applied to any non-incremental change → conceptual drift.

### C2. Christensen Disruption

- **Central question**: When and why do incumbents fail to respond to low-end / new-market innovations?
- **Canonical**: Christensen 1997 *Innovator's Dilemma*; Christensen, Raynor & McDonald 2015 HBR (reclarification).
- **Recent UTD24 in lineage**: [CITATION NEEDED — user supplies; see "Recent-anchor search guide" below for query template] (disruption has been heavily critiqued — engage Lepore 2014, King & Baatartogtokh 2015 MIT SMR).
- **Typical method**: longitudinal case studies; some archival.
- **Outlet fit**: SMJ, AMJ, OS (case-based).
- **Mis-application warnings**:
  - Using "disruption" loosely for any incumbent decline → reviewer reject. UTD24 reviewers require precise definitional adherence.

### C3. Ambidexterity (Tushman-O'Reilly, Gibson-Birkinshaw)

- **Central question**: How do firms balance exploration and exploitation to sustain performance?
- **Canonical**: March 1991 OS; Tushman & O'Reilly 1996 *CMR*; Gibson & Birkinshaw 2004 AMJ; Raisch & Birkinshaw 2008 *J Management*.
- **Recent UTD24 in lineage**: [CITATION NEEDED — user supplies; see "Recent-anchor search guide" below for query template]
- **Typical method**: survey of managers; archival panel.
- **Outlet fit**: AMJ (primary), SMJ, OS.
- **Mis-application warnings**:
  - Ambidexterity measured as 2-item construct → construct validity reject.

### C4. Recombinant Innovation / Search

- **Central question**: How does the structure of prior knowledge (depth, breadth, network position) shape novel combinations?
- **Canonical**: Fleming 2001 *Management Science*; Katila & Ahuja 2002 AMJ.
- **Recent UTD24 in lineage**: [CITATION NEEDED — user supplies; see "Recent-anchor search guide" below for query template]
- **Typical method**: patent-based archival panel.
- **Outlet fit**: SMJ, AMJ, MS (Strategy section).

## D. Entrepreneurship lineages

### D1. Opportunity Discovery vs Creation (Shane-Venkataraman, Alvarez-Barney)

- **Central question**: Do opportunities exist objectively to be discovered, or are they socially constructed?
- **Canonical**: Shane & Venkataraman 2000 AMR; Alvarez & Barney 2007 *Strategic Entrepreneurship J*; Davidsson 2015 *J Business Venturing*.
- **Recent UTD24 in lineage**: [CITATION NEEDED — user supplies; see "Recent-anchor search guide" below for query template]
- **Typical method**: qual case; survey of founders; sometimes experiment.
- **Outlet fit**: ASQ, AMJ, AMR (theory); JBV is FT50 but not UTD24.
- **Mis-application warnings**:
  - Treating discovery vs creation as binary without engaging Davidsson 2015 critique.

### D2. Effectuation (Sarasvathy)

- **Central question**: Under uncertainty, how do experienced entrepreneurs reason from means rather than goals?
- **Canonical**: Sarasvathy 2001 AMR; Read et al. 2009 *J Marketing*; Chandler et al. 2011 *J Business Venturing*.
- **Recent UTD24 in lineage**: [CITATION NEEDED — user supplies; see "Recent-anchor search guide" below for query template]
- **Typical method**: experiments / verbal protocols; survey scales (Chandler 2011 validation).
- **Outlet fit**: AMJ (rare), AMR, Strategy Science; JBV / *Journal of Business Venturing* primary.
- **Mis-application warnings**:
  - Effectuation conflated with bricolage or lean startup → distinct constructs.

### D3. Resource Bricolage (Baker-Nelson)

- **Central question**: How do resource-constrained entrepreneurs construct new resource portfolios from materials at hand?
- **Canonical**: Baker & Nelson 2005 ASQ; Senyard et al. 2014 *J Product Innovation Management*.
- **Recent UTD24 in lineage**: [CITATION NEEDED — user supplies; see "Recent-anchor search guide" below for query template]
- **Typical method**: qual case (ASQ tradition); survey scales.
- **Outlet fit**: ASQ, AMJ.

### D4. Founder Identity / Imprinting (Powell-Baker, Fauchart-Gruber)

- **Central question**: How do founder identities and imprinting shape venture strategy and persistence?
- **Canonical**: Fauchart & Gruber 2011 AMJ; Powell & Baker 2014 AMJ; Marquis & Tilcsik 2013 *AMA*.
- **Recent UTD24 in lineage**: [CITATION NEEDED — user supplies; see "Recent-anchor search guide" below for query template]
- **Typical method**: longitudinal qual; sometimes archival with founder backgrounds.
- **Outlet fit**: AMJ, ASQ.

### How to use these queries

The user can paste these into Google Scholar, Web of Science, Scopus, or a research assistant (the `research-lit` skill is appropriate). When results return, the user supplies 2-3 papers per lineage and the skill audits whether they are:

- **Recent** (≤ 5 years)
- **Central** to the lineage (highly cited within the lineage; cited by other recent UTD24 papers in the lineage)
- **From a UTD24 outlet** (or AMR / Strategy Science / SEJ)

If the user's supplied papers do not pass these checks, the skill flags the gap and asks for replacement.

### Out-of-UTD24-tier exemplars (for context)

When a lineage is mature, some recent anchors may be in FT50-but-not-UTD24 outlets (JBR, LRP, APJM, MOR, SO). These are useful for context but should not be the *only* recent anchors for a UTD24-targeting paper.

## E. Cross-lineage integration patterns (UTD24 favorites)

Integration moves that have a track record of being accepted at UTD24:

1. **Behavioral × Strategic Capabilities** — e.g., aspirations and capability development → AMJ-natural
2. **Cognitive × Ecosystem** — e.g., how managerial mental models of complementor moves shape ecosystem decisions → SMJ / Strategy Science
3. **Attention × Recombinant Search** — e.g., how attention focus channels search distance → SMJ / MS
4. **TMT × Dynamic Capabilities** — e.g., managerial cognitive capability as Helfat-Peteraf microfoundation → SMJ
5. **Opportunity × Bricolage** — e.g., how opportunity creation reshapes available material at hand → ASQ

**Do not propose an integration the user did not already gesture at.** Suggest, do not impose.
