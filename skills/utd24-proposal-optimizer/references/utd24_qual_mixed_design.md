# UTD24 Qualitative and Mixed-Methods Design — acceptance criteria

This file is the **qualitative / mixed-methods authority** for DESIGN mode (and for MANUSCRIPT / REVIEW mode when the paper is qual or mixed).

UTD24 outlets are quantitatively-skewed, but **ASQ and AMJ** have established qualitative traditions, and **OS** publishes ambitious qual / mixed papers. The bar is different from quantitative work: instead of identification rigor, the bar is **theoretical depth, methodological transparency, and richness of insight**.

Common failure: writing a qual paper as if it were a quan paper (with hypotheses to test rather than questions to develop), or running quan analyses on qual data without theoretical scaffolding from the qual side (mixed-methods done wrong).

---

## Section Q1 — Qualitative paradigms and which UTD24 outlets accept them

| Qualitative tradition | Core logic | UTD24 acceptance |
|---|---|---|
| **Grounded theory** (Glaser & Strauss 1967; Strauss & Corbin 1998; Charmaz 2014) | Theory emerges from systematic coding of data; aims to build new theory grounded in observations | ASQ ✓✓ / AMJ ✓ / OS ✓; rare elsewhere |
| **Process / longitudinal case** (Pettigrew 1990; Langley 1999; Van de Ven 2007) | Trace how outcomes unfold over time through identifiable events, decisions, interpretations | ASQ ✓✓ / AMJ ✓✓ / OS ✓ |
| **Multi-case Eisenhardt** (Eisenhardt 1989; Eisenhardt & Graebner 2007) | Theoretical-replication logic across 4-10 cases to build mid-range theory | AMJ ✓✓ / ASQ ✓ / OS ✓; common at SMJ when blended with quant |
| **Ethnography** (Van Maanen 1979, 2011) | Deep immersion in single site; produces rich descriptions of routines, meanings, practices | ASQ ✓✓ / AMJ △ (rare); accepted at OS |
| **Discourse / narrative / rhetorical analysis** | Examines how language constructs strategic meaning | ASQ ✓ / OS ✓; rare elsewhere |
| **Critical / interpretive case** | Examines power, identity, ideology, with explicit interpretive stance | OS ✓ / ASQ △ (rare); often at *Organization* (not UTD24) |
| **Comparative-historical** (Pierson 2004; Mahoney 2010) | Compares cases across time / context; emphasizes path dependence, conjuncture | ASQ ✓ / AMJ △ / OS ✓ |

For each, see the UTD24 outlet's recent published qual exemplars to anchor expectations.

## Section Q2 — Common UTD24 qualitative methods checklist

A UTD24-acceptable qualitative paper typically includes the following methodological elements. Use this as both a design checklist (DESIGN mode) and an audit checklist (MANUSCRIPT mode, when the paper is qual).

### Q2.1 Site selection and sampling

- **Site selection rationale**: why this site / these cases? (Often: extreme / polar / revelatory / theoretical-replication / longitudinal-access)
- **Theoretical sampling logic** (Eisenhardt-Graebner 2007): cases chosen for theoretical reasons, not convenience
- **Sample size justification**: typically 4-10 cases for multi-case; single case requires extra defense (revelatory / polar / extreme case)
- **Saturation argument**: when did the researcher know they had enough data? (theme saturation, theoretical saturation)

### Q2.2 Data collection

- **Multiple data sources** (UTD24 norm): interviews + archival + observation + documents; triangulation across at least 3 sources
- **Interview protocol**: semi-structured, evolving with theory; report number of interviews, duration, transcription approach
- **Real-time vs retrospective**: real-time observation strongly preferred for process studies; retrospective interviews must be triangulated with archival
- **Duration**: longitudinal studies should be 12-36 months minimum at ASQ; can be shorter at AMJ for multi-case
- **Informant range**: multi-level (top, middle, line managers); multi-perspective (different functions)

### Q2.3 Data analysis

- **Coding approach**: open coding → axial coding → selective coding (Strauss-Corbin) OR Gioia methodology (1st-order concepts → 2nd-order themes → aggregate dimensions) OR Eisenhardt within-case + cross-case
- **Coding documentation**: provide the data structure (e.g., Gioia data-structure figure) so readers can trace from raw data to themes
- **Inter-rater agreement** (if multi-coder): report explicitly, even for qualitative work
- **Use of software**: NVivo / Atlas.ti / Dedoose — document version and analysis trail

### Q2.4 Trustworthiness criteria

Lincoln-Guba (1985) trustworthiness criteria, customary at UTD24:
- **Credibility**: prolonged engagement, persistent observation, triangulation, member checks (member checks not universal at strategy outlets)
- **Transferability**: thick description allowing reader to assess transferability
- **Dependability**: audit trail (chain of evidence)
- **Confirmability**: reflexivity statement about researcher's positionality

### Q2.5 Reporting transparency

- **Data table**: typical at AMJ — table of informants / interviews / data sources
- **Power quotes**: representative quotations with informant ID
- **Data-structure figure**: Gioia-style figure showing 1st-order to aggregate dimensions
- **Process model**: typical at ASQ — model of the process unfolding (boxes-and-arrows or temporal flow)

## Section Q3 — Gioia methodology (most common UTD24 qualitative approach since 2013)

Gioia, Corley & Hamilton (2013) *Organizational Research Methods*; subsequent extensions in Gioia (2021) *JBI*.

Structure:
1. **1st-order concepts**: informant-centric terms grouped from coding
2. **2nd-order themes**: researcher-centric theoretical categories
3. **Aggregate dimensions**: broader theoretical aggregations
4. **Data-structure figure**: visual showing the 1st → 2nd → aggregate progression
5. **Grounded theoretical model**: process or boxes-arrows model derived from the data structure

UTD24 qual papers since ~2014 frequently use this structure. Reviewers expect to see the data structure figure.

Common failure: presenting the model without the data structure (skips the bridge); or presenting the data structure without integrating into a coherent process model.

## Section Q4 — Process-study methods (Langley 1999; Langley & Tsoukas 2017)

Langley (1999) *AMR* identifies seven strategies for theorizing from process data:
1. Narrative strategy
2. Quantification strategy
3. Alternate templates strategy
4. Grounded theory strategy
5. Visual mapping strategy
6. Temporal bracketing strategy
7. Synthetic strategy

Each has trade-offs. The 2017 update (Langley & Tsoukas eds.) extends with abductive reasoning emphasis.

For UTD24 process papers, **temporal bracketing** (Langley 1999) is among the most common: partition the timeline into theoretically meaningful periods, compare patterns across periods, theorize the transitions.

## Section Q5 — Multi-case Eisenhardt method specifics

Eisenhardt (1989) *AMR* and Eisenhardt-Graebner (2007) *AMJ* established the multi-case-for-theory-building tradition.

UTD24 expectations:
- **Number of cases**: 4-10 (fewer than 4 = single case; more than 10 = too thin per case)
- **Theoretical replication**: cases chosen to either replicate the theory (literal) or contrast (theoretical) — Eisenhardt-Graebner explicit table
- **Within-case analysis**: each case treated as standalone first
- **Cross-case analysis**: pattern matching across cases
- **Enfolding literature**: comparison to existing theory throughout, not just at the end
- **Theoretical saturation**: explicit argument that additional cases would not add theory

## Section Q6 — Mixed methods (qual + quan) designs

Mixed methods are increasingly accepted at UTD24 outlets, especially when the qual and quan complement each other on different aspects of the theoretical claim.

Common mixed-methods designs (Creswell-Plano Clark 2017):

### MM1 — Sequential exploratory (qual → quan)
Qual generates theory / measures / hypotheses; quan tests at scale.
- Strong at: AMJ, ASQ
- Common pattern: ethnography produces grounded model → survey or experiment tests key relationships

### MM2 — Sequential explanatory (quan → qual)
Quan reveals unexpected pattern; qual investigates mechanism.
- Strong at: SMJ (if qual is brief), AMJ
- Common pattern: archival panel shows X-Y relationship → field interviews probe why

### MM3 — Convergent / concurrent (qual + quan in parallel)
Both run simultaneously; convergence (or divergence) of findings discussed.
- Strong at: AMJ, OS
- Common pattern: survey + interviews on the same firms

### MM4 — Embedded (one method supports the other)
Qual or quan plays a supporting role.
- Common pattern: qual case study with embedded survey of the focal organization; or quan study with embedded interviews for measure validation

### Reporting requirements for mixed methods at UTD24

- **Integration paragraph**: explicit statement of how qual and quan integrate (not just "we did both")
- **Phase reporting**: clearly delineate which findings come from which method
- **Sequencing rationale**: defend why the chosen sequence (exploratory vs explanatory vs concurrent) fits the research question
- **Trade-off acknowledgment**: each method's limitations and how the other addresses them

Common failure: presenting qual and quan as parallel "studies" with no integration; reviewers reject this as "two papers, not mixed methods".

## Section Q7 — Outlet-specific calibration for qual / mixed

### ASQ
- **Strongest fit**: deep longitudinal qual (24+ months), ethnographic, process studies
- **Expected**: Gioia or Langley method; data structure figure or process model; thick description
- **Common rejection reasons**: retrospective interviews only (without real-time observation); single case without extreme/polar/revelatory justification; theoretical contribution unclear or under-developed despite rich data
- **Special note**: ASQ values "interesting" theoretical insight; even a beautifully-executed study may be rejected if the takeaway is not novel

### AMJ
- **Strongest fit**: multi-case Eisenhardt method (4-10 cases); mixed methods sequential
- **Expected**: explicit hypotheses or propositions even in qual papers; data table; power quotes
- **Common rejection reasons**: insufficient cases (under 4); weak cross-case analysis; mismatch between data and proposed theory; no integration in mixed methods

### OS
- **Strongest fit**: ambitious qual that integrates with theory novelty; mixed methods with strong theoretical motivation
- **Expected**: clear theoretical contribution; engagement with rival explanations
- **Common rejection reasons**: descriptive findings without theory; methodological choices not defended

### SMJ
- **Strongest fit**: rare; usually mixed methods where qual is supplementary (MM2 or MM4)
- **Expected**: when qual is present, the qual phase produces measures or hypotheses for quan testing
- **Common rejection reasons**: pure qual papers generally not fit; reviewer pool is quantitatively skewed

### AMR
- **Strongest fit**: conceptual papers (not qual per se); occasionally Gioia papers as "theory development from cases"
- **Expected**: AMR-grade theoretical contribution; propositions
- **Common rejection reasons**: empirical-grounding too thin to be conceptual; theoretical-grounding too thin to be empirical

### MS
- **Strongest fit**: rare; usually formal model + computational simulation
- **Expected**: when qual is present, it usually motivates formal model parameters
- **Common rejection reasons**: pure qual rarely fit at MS Strategy section

## Section Q8 — DESIGN-mode workflow for qual / mixed

When the user is designing a qual or mixed paper, walk through:

```
## Qualitative / Mixed Design Consultation

Site / case selection:
- Why this site / these cases? (theoretical rationale)
- Number of sites / cases
- Access mechanism and duration
- Theoretical sampling logic

Data collection plan:
- Sources (interviews / observation / archival / documents)
- Number of interviews planned (informant range)
- Duration (months / years)
- Real-time vs retrospective balance

Analysis approach:
- Method (Gioia / Langley temporal bracketing / Eisenhardt multi-case / grounded theory other)
- Coding software
- Coder count and inter-coder agreement plan
- Trustworthiness criteria (Lincoln-Guba)

Theoretical output target:
- Process model / grounded theory / mid-range theory / proposition set
- How it engages parent theory (extension / boundary / mechanism)

Mixed-methods integration plan (if applicable):
- Sequence (MM1 / MM2 / MM3 / MM4)
- Integration logic
- How qual and quan address different aspects of the claim

Outlet fit:
- Primary: ASQ / AMJ / OS / SMJ (rare)
- Submission strategy: ...

Common-failure pre-empt:
- (List 3-5 of the rejection reasons from Q7 most relevant to this design and pre-empt them)

Cross-skill handoff:
- For qual coding software guidance: outside this skill
- For trustworthiness audit at manuscript stage: re-run this file's Q2.4 checklist
```
