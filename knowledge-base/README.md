# Knowledge Base

这里是你真正的个人科研知识库，结构已经按我们之前讨论的逻辑重建好了。

## 设计原则

这个知识库不是为了“存文件”，而是为了支持 4 件事：

1. 找文献
2. 做综述
3. 产出选题
4. 推进论文项目

## 最小使用法

如果你不想一开始就太复杂，只维护下面 6 个目录：

- `00_首页与导航`
- `01_研究方向`
- `02_文献库`
- `03_理论库`
- `05_选题与Idea池`
- `09_项目库`

## 推荐工作流

1. 文献先进入 `02_文献库`
2. 有连续阅读后，汇总到 `06_专题综述`
3. 形成概念判断后，沉淀到 `03_理论库`
4. 产生研究机会后，写入 `05_选题与Idea池`
5. 开题或写作后，进入 `09_项目库`
6. 可复用表达和结构，沉淀到 `07_论文写作库` 与 `10_模板库`
