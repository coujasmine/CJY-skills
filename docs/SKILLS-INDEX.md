# Skills Index

## 总入口

### `ft50-paper-master`
适合整篇论文的全流程诊断、分 part 修改编排和最终英文润色。

## 分部件技能

### `ft50-part-abstract`
用于标题和摘要。

### `ft50-part-introduction`
用于研究问题、引言和选题合法性。

### `ft50-part-theory-dialogue`
用于 Theory/Literature Review，判断主干理论是否站得住。

### `ft50-part-theory-building`
用于理论建构、模型图说明、命题结构。

### `ft50-part-theory-hypotheses`
用于 Theory Framework 与 Hypotheses，强调近 5 年文献支撑。

### `ft50-part-mechanism`
用于机制链条和跳步修复。

### `ft50-part-construct-measurement`
用于新构念、量表、测量规范。

### `ft50-part-methods-results`
用于 Methods、Results 和 Robustness。

### `ft50-part-ai-ml`
用于 AI/ML 与管理研究结合的论文。

### `ft50-part-discussion-contribution`
用于 Discussion、Limitations、Conclusion 的整合收束。

### `ft50-academic-english-polish`
用于最后的学术英语润色，不替代结构与理论层修改。

## 推荐调用顺序

1. 整篇稿件：`ft50-paper-master`
2. 单独部分：对应 `ft50-part-*`
3. 全文定稿前：`ft50-academic-english-polish`

## 什么时候不要直接用 skill

- 你只是想长期存文献和观点：用 `knowledge-base/`
- 你还在发散选题、没形成论文草稿：优先 `knowledge-base/05_选题与Idea池/`
- 你在做综述和理论梳理：先写进 `knowledge-base/06_专题综述/` 和 `03_理论库/`
